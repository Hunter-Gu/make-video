# The Library of Alexandria

A 52-second, 16:9 English knowledge-video demo for a general audience. It uses
a restrained historical-documentary style to introduce Alexandria, correct the
single-fire simplification, and close on the library's cultural legacy.

The demo uses supplied illustration and video fixtures plus the complete
knowledge-scene library. Narration is represented as captions; generated voice
and music are intentionally excluded so the acceptance case renders without
API access. The same composition accepts generated voice, music, and SFX tracks
through render props.
